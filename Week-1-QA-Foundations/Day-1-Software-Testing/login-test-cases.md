# Day 1 – Introduction to Software Testing

## Project: Online Shopping Website

**Role:** Junior Manual QA Tester

**Testing Type:** Functional Testing

### 1. Testing Objective

The objective was to test the login functionality of an online shopping website and verify that it handles valid and invalid login information correctly.

### 2. Test Scenarios

| Test ID | Scenario | Expected Result |
|---|---|---|
| TC001 | Valid login | User successfully logs in |
| TC002 | Incorrect password | Appropriate error message appears |
| TC003 | Empty fields | Validation message appears |
| TC004 | Invalid email | Email validation message appears |
| TC005 | Short password | Password validation message appears |

### 3. Test Execution Results

| Test ID | Actual Result | Status |
|---|---|---|
| TC001 | Login successful | PASS |
| TC002 | Error message displayed | PASS |
| TC003 | Validation message displayed | PASS |
| TC004 | Invalid email message displayed | PASS |
| TC005 | Short password validation displayed | PASS |

### 4. Testing Summary

- Total test cases: 5
- Passed: 5
- Failed: 0
- Blocked: 0

**Pass rate: 100%**

### 5. What I Learned

- Understanding software testing.
- Creating test scenarios.
- Writing test cases.
- Understanding expected and actual results.
- Executing test cases and recording results.

### 6. Conclusion

All five login test cases were executed successfully. The actual results matched the expected results.

This exercise helped me understand the fundamentals of manual software testing and the importance of documenting test results.
